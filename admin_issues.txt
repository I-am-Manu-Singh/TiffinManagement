Key Takeaways & Recommended Roadmap
Replace Synthetic IDs: Eliminate System.currentTimeMillis() for entity creation across Admin modules; use Supabase UUID generation.
Normalize Roles & Categories: Reconcile UI role strings ("Head Cook", "Delivery Lead") with Postgres enum definitions ("kitchen_staff", "driver").
Connect Real Date Pickers: Replace hardcoded "Today" string states with Material3 DatePickers.
Implement Actual Database Transactions: Wrap wallet adjustments, holds, and order overrides into Supabase RPCs with ledger verification.
